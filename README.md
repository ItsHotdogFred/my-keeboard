My Keeboard

This my custom TKL inspired keyboard which was originally made for the KEEB event at Hackclub but was transferred to fabricate. This is a keyboard design specificly for my use cases. Such as 2 rotary encoders for sound and microphone volume which allows for quick muting of the mic. The width matches the arm wrist of my current keyboard and also rgb because rgb is cool.
